# AI 洗文案

只处理当前口播文字、产品名和可选改写要求；不处理媒体或自动发布，不保证平台过审。

## 操作与失效

- 优化结果显示在独立预览；只有点击「采用新稿」才替换编辑框，未手工编辑时可撤销采用。
- rewrite 与旧 AI 写作模式共用忙锁。设置读取、生成覆盖确认、服务商同意、模型请求和结果确认均在锁内；成功、取消、异常均释放。
- 任一新 AI 写作操作开始即撤销旧 rewrite 预览的采用资格。
- 请求期间编辑原稿会废弃本次 generation，编辑后改回原字节也不会接收旧响应。切商品、改写要求变化同样不会把旧请求结果当作当前结果。
- 界面重绘继承忙状态，生成/优化按钮不能因为重绘重新可用。
- 切换商品前保留各自草稿，先刷新新商品编辑框再加载数据，避免串稿；明确清空的草稿不会恢复成旧稿。

## 服务端

rewrite 使用独立 system，不改变旧模式的 system、请求参数或响应提取语义。输出预算为 6000 tokens，正文仍限 3000 字；预算不能替代完整性校验：若服务商返回 `finish_reason`，必须为 `stop`，否则拒绝，包括 `length`、`content_filter`、工具调用、null 等。兼容旧端点缺失该字段，但缺失元数据时无法依此检测截断。

多稿按单独一行 `---` 分隔并校验块数；块数相同不等于语义或顺序已获自动验证。

## 文案质量门禁

非医疗日用品不得保留「身体不适→使用→松快」因果链，也不能换成「需要→使用→放松」。删除整条症状、人群和体验链，不补写家人常备、自己用过、功能或场景。事实不足时允许缩短为中性介绍或查看标签/说明的建议，不为长度补卖点。

不得用「方便、省心、好用、舒适」等未经证实的评价替代已删除的承诺。

提示词结构测试不等于真实模型质量测试。风险样本（日用贴布；长辈不得劲、酸胀贴一贴、忙完松快）需单独执行真实模型并审核。修复作者只运行隔离测试；发布验收另行完成了 Windows 真实模型合成文本测试及真实浏览器交互，不能将这些有限样本当成任意未来文案的审核保证。
