# 克隆音色文件夹

把音频文件直接放进这个文件夹，工作台里就会出现对应的「Vox 声音」：

- 文件名就是音色名：`女声 1.wav` → 配音列表里出现「女声 1」
- 支持格式：`.wav` `.mp3` `.m4a` `.flac` `.ogg` `.aac`（非 wav 会自动转码一次，原文件不改动）
- 音频建议：5~30 秒、单人、尽量干净（无背景音乐最好，轻 BGM 也可用）
- 放好后在工作台「Vox 声音」旁点「刷新音色」即可；
- 同名文件优先取 .wav；文件名不要以点开头或包含 `\ / : * ? " < > |`
- 克隆音色只在本机使用，不会上传到任何服务；请使用本人或已获授权的声音。

说明：文件夹里放一个示例文件也可以——删除后刷新列表即消失。
