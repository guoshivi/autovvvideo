# autovvvideo

**Windows 本地视频出片工作台**：把一批素材视频 + 一段口播文案，自动做成一条竖屏带货短视频。

流程：**按文案语义选镜 → AI 配音 → 逐句字幕 → BGM 混音 → 导出 1080×1920 成片**。
画面理解、配音、剪辑全部在本机 NVIDIA 显卡上运行，素材与成片只存在本机，不上传。

> 这不是"一句话从零生成画面"的工具。它需要你**自备素材视频**（产品实拍、场景素材），
> 它做的事是"把已有素材按文案节奏自动剪成片子"。

---

## 机器要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 64 位 |
| 显卡 | NVIDIA（需要 CUDA + BF16）；驱动建议 580 以上（CUDA 13 要求） |
| 磁盘 | 预留 ≥ 30 GB（首次安装需联网下载约 10–15 GB：两套独立 Python 环境 + 两个模型 + 工具） |
| 内存 | 32 GB 以上推荐（观测机器 32 GB） |

实测记录：在 **RTX 5060 8GB + 32GB 内存**的 Windows 机器上完整验证通过。
**RTX 3080 Ti 未在本仓库实测**，请按 `docs/DEPLOY.md` 装好后，实际出一条片作为验收。

## 快速开始（安装完成后）

1. 双击桌面 **autovvvideo** 图标（无终端窗口，自动开服务 + 独立应用窗口）
2. ①选择素材文件夹 → 建索引；②写文案（或点 **✨AI 生成**）；③点「开始出片」
3. 成片出现在「结果」区，可播放、下载

**首次安装必须由 AI 助手执行**：把整个仓库交给你电脑上的 AI agent，让它按
**`docs/DEPLOY.md`** 一步步安装与验收（安装、下载、校验、体检脚本都准备好了）。

## AI 文案（可选）

- 打开「✨ AI 生成」面板 → 底部「AI 接口设置」：填**接口地址**和**密钥**即可
  （任何 OpenAI 兼容服务，如 DeepSeek）；「高级」里可选填模型名称
- 密钥只保存在本机 `config/ai-config.json`（不进仓库、不回显）；使用 AI 时，
  文案与产品信息会发送给你所填写的服务商

## 目录结构

```
workbench/          服务端代码（HTTP 服务、任务队列、渲染、索引、AI 文案）
static/             网页界面
reference/          素材理解 / 字幕绘制等核心模块
install.ps1         安装（下载→校验→两套独立环境→模型→桌面图标）
doctor.ps1          体检（环境/模型/FFmpeg/AAC/GPU，输出 PASS/WARN/FAIL）
update.ps1          更新源码（保留配置/数据/模型）
launch.vbs          无窗口启动器（桌面图标用）
deploy/             依赖清单（含官方下载地址与校验值）、体检与发布检查脚本
docs/               DEPLOY.md 部署手册 · SECURITY.md 安全说明 · THIRD_PARTY_NOTICES.md
config.example.json 配置模板（安装时自动生成正式配置）
```

素材、模型、工具、环境、成片全部落在本目录（`.gitignore` 已排除，不会进仓库）。

## 更新

```
powershell -ExecutionPolicy Bypass -File .\update.ps1
```
只更新源码，不动配置/数据/模型；更新前自动备份到 `data/backups/`。

## 安全与网络

- 服务默认只监听 `127.0.0.1`（本机）。**不要直接暴露到公网**。
- 局域网共享使用前请先读 `docs/SECURITY.md`。
- AI 密钥只存本机；AI 请求的只有文案文本，不含素材和成片。
