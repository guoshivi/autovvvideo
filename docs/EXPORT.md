# 商品名编号导出
- 新成片保存为：`选定输出目录/商品名/YYYYMMDD/商品名 N.mp4`，日期取导出时服务器本地日期。
- 商品名优先；只有商品名为空时才回退到文案第一句，再为空使用「视频」。
- 文件夹与文件前缀共用安全化规则：最多 80 字符，清除控制/路径非法字符，处理 Windows 设备名，截断后去掉尾部点和空格。
- 同商品同日扫描已有编号，以最大编号加一续写；原生 no-replace 发布，遇到并发碰撞继续续号，最多重试 200 次，不补旧空洞、不覆盖旧文件。
- 输出文件夹只新增 MP4；封面与质检报告仍保留在工作台任务内部；既有导出文件及旧文件夹均不移动、不删除。
- 发布前验证质检报告、SHA/大小和输出授权；逐级检查商品/日期目录，复制与发布前后复核完整目录身份链；发布后失败保留成片及异常 receipt，需人工核对而非覆盖重跑。
- 输出目录选择器、配音与原质检流程不变；回滚功能可还原 `workbench/renderer.py`、`workbench/service.py`，并将 `static/index.html` 页脚说明一并还原。
