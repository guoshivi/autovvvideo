# Qwen / Vox 配音试用

## 你会看到什么

工作台增加「配音」选择：**Qwen（原配音）**与 **Vox（新配音·试用）**，以及直接可见的声音选择和「试听当前配音」。默认仍为 Qwen，旧商品、旧任务保持原说话人，不自动换模型。

Vox 的风格预设：自然分享女声、清晰活力女声（不喊叫）、沉稳成熟男声、温暖叙事女声。这是自建风格，不是复制剪映的专有音色；实际听感需在你的 Windows 上试听后决定。

## 目标 Windows 上怎么装

先退出工作台，在已有的项目目录更新代码：

```powershell
git pull --ff-only
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-vox.ps1
```

前提是已按 [DEPLOY.md](DEPLOY.md) 安装原工作台。可选安装创建独立的 `.runtime\vox`，下载并校验固定的 VoxCPM 2.0.3 和官方 VoxCPM2 模型快照，再写入本机配置中的 `voxcpm_python`、`voxcpm_model`、`voxcpm_cache`。不覆盖 `.runtime\tts`、`.runtime\embedding`、原 AI 接口设置或用户任务。

安装后可检查而不下载：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-vox.ps1 -CheckOnly
```

检查通过仅表示安装、校验与运行环境检查通过，不等于模型成功合成或音质通过。打开原桌面图标后强刷新页面，再做下面的实际试用。

## 怎么选、怎么听

1. 选择商品，填写口播文案。
2. 「配音」选 Qwen 或 Vox，再选声音和语速。
3. 点「试听当前配音」。试听不需要先建素材索引，也不会创建出片任务。
4. 首次使用某个 Vox 音色会准备本地参考样音，可能比后续试听慢；同一预设的后续句子复用同一参考声音，不逐句重新随机设计。
5. 合适就开启「语音」，按原流程建索引并出片。不合适可切回 Qwen；两种方式分别保留声音选择，切换不丢正在编辑的文案。

未安装 Vox 时会明确提示运行安装入口，**不会暗中改用 Qwen**。同时只接受一个试听生成；生成期间改变文案或声音，旧请求返回的音频不会被标成当前设置的试听。

## 目标机实际验收

- 两种配音都生成一段真实试听并能播放；文件不是空音频。
- 同一稿切换两种方式，试听后确认自然度与声音偏好。
- Vox 连续多句试听/出片，检查声线一致、无明显漏字、尾句完整、语速确实变化。
- Vox 实际生成一条含语音、字幕的成片；再用 Qwen 生成一条原流程成片。
- 模型加载/CUDA、真实音色、跨句稳定与完整出片均以本机实际结果为准。失败保留错误原文，不以 `pip check` 或安装检查代替出片验收。

## 克隆自己的声音（丢文件夹即用）

把一段干净的人声录音放进项目根目录的 `voices\` 文件夹，配音列表就会多出对应音色；点「刷新音色」后即可试听、出片：

- 文件名 = 音色名（如 `女声 1.wav` → 列表出现「女声 1」）。支持 wav/mp3/m4a/flac/ogg/aac；非 wav 会自动转码一次，原始文件不改动。
- 建议 5~30 秒、单人、尽量干净；带轻微背景音乐的成片音轨也可用（输出不带音乐）。
- 删除文件后刷新即消失；试听/出片时找不到文件会明确报错，绝不会换成别的音色。
- 仅使用本人或已获授权的声音。
