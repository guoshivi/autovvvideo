# 自动清理与记录清理

出片任务成功提交并确认成片文件大小与收据一致后，工作台默认清理任务目录中的中间文件。开关位于任务队列上方的“出片成功后自动清理中间文件”，设置保存在 `<data_root>/prefs.json`；缺失或损坏时默认开启。清理只删除 `cut_*.mp4`、`draft.mp4`、`beauty-*`、`captioned-*`、`card_*.mp4`、配置字体副本、`*.f32`/`*.f32.tmp` 和 `voice-intermediate/`。`final-codec/`、`final.mp4`、各类收据、日志、字幕、封面和 `voice_*.wav` 会保留；符号链接不会跟随删除。

“清理已结束记录”先提供 dry-run 统计，再删除商品下完成、失败、已取消、已中断的账本记录及其本机任务目录。NAS 素材、输出文件夹和已导出的成片不受影响。账本删除失败时不会删除目录；目录中的链接会跳过并记录错误。

磁盘保护阈值由配置 `min_free_bytes` 控制，默认 1.5 GiB，最小允许 100 MiB。工作线程发现剩余空间低于阈值时暂停接单，每 30 秒复查，服务关闭可立即打断；空间恢复后自动继续。
