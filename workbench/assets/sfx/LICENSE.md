# 音效素材许可

本目录包含三类音效，全部允许商用、无需署名：

1. **本机合成**：`ding.wav`、`pop.wav`、`whoosh.wav`、`click.wav`、`coin.wav`、`success.wav`，由本项目用 FFmpeg/NumPy 生成。
2. **Kenney Audio（CC0-1.0）**：`switch.wav`、`rollover.wav`、`error.wav`、`notify.wav`、`sparkle.wav`、`powerup.wav`、`slide.wav`、`cash.wav`、`win.wav`，取自 Kenney 素材包的 UI / Digital / Casino 片段，重采样为 24kHz 单声道。
   https://kenney.nl/assets · https://github.com/iwenzhou/kenney
3. **UI SFX（音频 CC0，代码 MIT）**：`cart.wav`、`purchase.wav`、`coupon.wav`、`checkout.wav`、`reward.wav`、`achievement.wav`、`levelup.wav`、`warn.wav`、`swipe.wav`、`hover.wav`、`toggle.wav`、`complete.wav`，取自 `romainsimon/uisfx` 的 `soft` 音色包，重采样为 24kHz 单声道。
   https://github.com/romainsimon/uisfx · 音频许可见其 `LICENSE-AUDIO`
