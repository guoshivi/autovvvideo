# 结果下载的 Range 行为

`/api/results/{job}?product_id=...` 对已完成且摘要仍匹配的结果提供单段字节范围下载。

- 不带 `Range`：返回 `200` 和完整内容。
- `bytes=a-b`：返回 `206`，范围为闭区间 `a..b`。
- `bytes=a-`：返回从 `a` 到末尾的内容。
- `bytes=-N`：返回最后 `N` 个字节；当 `N` 大于文件长度时返回完整文件。

成功的范围响应带有 `Content-Range: bytes start-end/total`、准确的
`Content-Length` 和 `Accept-Ranges: bytes`。每次下载仍会先校验结果摘要与字节数，
并从同一份已校验的临时快照发送内容（小文件在内存中，较大文件会暂存到磁盘）。

零长度后缀和起点超出文件会被拒绝并返回 `416`，同时返回 `Content-Range: bytes */total`。
格式错误和多段范围按既有错误语义返回 `400`。现有的有界范围超出文件末尾仍按原有规则
拒绝；这次修复只处理后缀范围的终点计算，不改变鉴权、商品范围、任务状态、摘要校验或
快照边界。

这里仍是窄范围实现：不支持多段 Range，也不扩展为完整 RFC Range 解析器。
