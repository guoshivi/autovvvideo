# Vox 固定提示音频

Vox 每个预设或克隆音色现在都会在 `voxcpm_cache/<voice>/` 保存一对固定提示材料：
`prompt.wav` 与 `prompt.json`。首次使用时，系统用固定短语“大家好，今天和你分享一个实用的小发现。”生成自然语速提示音频，要求自然停止、时长 1.6–6.5 秒且周期度中位数至少 0.60；之后每句同时传入原参考音频、提示音频和精确短语，以保持音色与句首稳定性。

每次使用都会校验模型绝对路径、模型版本、种子、短语以及两个 SHA-256。校验失败会报“Vox 提示缓存校验失败，请清理该音色的提示缓存后重试”，不会静默覆盖。若参考 WAV 的 SHA-256 发生变化，系统会用临时文件完成质检后原子替换这一音色的提示对；生成连续三次未通过质检会提示更换或重新放入更清晰的参考音频。

如需清理缓存，停止当前 Vox 任务后删除对应音色目录中的 `prompt.wav` 和 `prompt.json`，下次使用会重新冷生成。不要删除仍在使用的 `anchor.wav` 或克隆源文件。
