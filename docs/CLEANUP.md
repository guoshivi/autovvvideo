# 自动清理与记录清理

出片任务成功提交后，工作台会先确认“完成”账本行已经持久化并独立读回，再独立核对导出文件的 SHA-256 和字节数，默认才清理任务目录中的本地成片临时文件。开关位于任务队列上方的“出片成功核验后清理本地成片临时文件（失败保留）”，设置保存在 `<data_root>/prefs.json`；缺失或损坏时默认开启。清理只删除 `cut_*.mp4`、`draft.mp4`、`beauty-*`、`captioned-*`、`card_*.mp4`、配置字体副本、`*.f32`/`*.f32.tmp`、`voice-intermediate/`，以及已核验后不再需要的根目录 `final.mp4` 和 `final-codec/codec-*/` 下的 `master.wav`、`audio.m4a`、`final.mp4`、`final-decoded.f32*`。报告、收据、日志、字幕、封面、缩略图和 `voice_*.wav` 会保留；导出目录中的成片仍可从结果区播放或下载。任何失败、缺少回读或输出异常都会保留本地文件并记录错误；符号链接不会跟随删除。

“清理已结束记录”先提供 dry-run 统计，再删除商品下完成、失败、已取消、已中断的账本记录及其本机任务目录。NAS 素材、输出文件夹和已导出的成片不受影响。账本删除失败时不会删除目录；目录中的链接会跳过并记录错误。

磁盘保护阈值由配置 `min_free_bytes` 控制，默认 1.5 GiB，最小允许 100 MiB。工作线程发现剩余空间低于阈值时暂停接单，每 30 秒复查，服务关闭可立即打断；空间恢复后自动继续。
